# Arta Abdullahu website

A simple, single-page website for Arta Abdullahu. The current draft describes data cleanup, automation, dashboards, and grant reporting support for women-led NGOs in Kosovo.

## Files

- `dist/index.html` — the complete page, including its styles and small script. There is no framework or build step.
- `.openai/hosting.json` — configuration for the current private Sites preview.

## Edit and preview

Open `dist/index.html` in Visual Studio Code or another text editor. Save your changes, then open that file in a browser to preview them locally. You can also use VS Code's Live Server extension for automatic refresh, but it is optional.

The page currently has no email link or contact form. Add a verified contact address before inviting visitors to get in touch.

## Publish and domain

The existing draft is hosted separately from `artaabdullahu.com`. Saving code on GitHub does not automatically connect or update that domain. To publish future edits, deploy the updated site through Sites or configure a separate static host such as GitHub Pages, then connect the domain in your DNS settings.

## Project history

Keep this repository under Git version control. Use commit messages that say what changed, such as `Update services text` or `Add contact email`. Do not commit passwords, API keys, or private client data.
